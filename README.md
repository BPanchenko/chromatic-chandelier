# ПО "Цветная Люстра". Реализация [цифровой палитры цвета](https://palette.protosite.xyz/)

ПО "Цветная Люстра" генерирует дополнительные оттенки для выбранного цветового решения, в экземпляре класса палитры. Дополнительные цвета генерируются на основе алгоритма управляемого параметрами конфигурации палитры. В совокупности взаимосвязанные наборы цвета организованы в логическую структуру, цветовую схему цифрового продукта. В результате изменения параметров алгоритма ПО "Цветная Люстра" будет перестраивать оттенки основных цветов для сохранения гармоничности цветового решения.
